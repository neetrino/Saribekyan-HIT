# Module design records

Այս պանակում պահվում է մեկ design record յուրաքանչյուր իրական custom կամ materially configured module-ի համար։ Դատարկ/ենթադրվող module record չի ստեղծվում մինչև ownership-ը և Phase I requirement mapping-ը հստակ չեն։

Module record-ը լրացվում է [MODULE-TEMPLATE.md](./MODULE-TEMPLATE.md)-ով և հղվում է traceability register-ից։ OpenMRS community module-ի համար նույն template-ը օգտագործվում է՝ նշելով `reuse/configure`, exact version, fit-gap և upgrade owner-ը։
