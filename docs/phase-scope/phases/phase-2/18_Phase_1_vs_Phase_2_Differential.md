# Граница Фазы I и «расширений» Фазы II

> **Статус:** исторический differential analysis исходного vision, не нормативный scope, не список открытых вопросов и не coding authorization. Граница nursing для Phase I закрывается только `INP-08` подписываемого ТЗ; слова `частично определена`, повторы и ссылки на §6.3.5/§7.5 ниже не переоткрывают её и не переносят функции между фазами. Phase II требует нового подписанного scope/change request и go-решения.

Исторический источник evidence: исходный vision HIS. Номера строк ниже сохраняются только как происхождение анализа; исполняемой ссылки на vision нет, и этот файл не является способом получить scope будущей фазы.

Цель файла — не придумывать расширения, а показать три разных ситуации:

- **граница определена** — источник ясно описывает базу I и добавку II;
- **дублирование** — функция описана и в I, и во II;
- **расширение не раскрыто** — слово «расширенный» есть, но функций в источнике нет.

## Сильнейшая рабочая граница по источнику

1. Аптека/склады и полное управление операционной имеют прямое основание не входить в I.
2. Койки, медицинские документы и отчёты Phase I закрываются ID подписанного ТЗ. Nursing Phase I закрывается только `INP-08`. Историческая пометка о повторном подтверждении глубины scope не открывает и функции Фазы II в I не переносит.
3. Внешняя страховая интеграция не является частью базового I.
4. HR/payroll прямо исключены из I и не могут быть оценены для будущих фаз до появления требований.

## Что источник не позволяет определить

Для трёх названных «расширений» II — койки, медицинские документы и операционные отчёты — нет ни функций, ни критериев приёмки. Поэтому корректный статус сейчас:

> **Фаза II — направление развития; точный scope и стоимость определяются отдельным согласованием.**

Если клиент хочет видеть их как уже определённую поставку II, он должен дать отдельное функциональное описание.
