# Հետ կանչված պատմական հաճախորդի պարզաբանման գրառում

> **Կարգավիճակ՝ WITHDRAWN_FROM_ACTIVE_DOCUMENTATION_SURFACE / NON_AUTHORIZING**

Նախկին հանդիպման ամփոփումը հեռացվել է, քանի որ բանավոր կամ ընդհանուր համաձայնությունը հաստատման ապացույց չէ և կարող էր սխալմամբ ընկալվել որպես հաճախորդի հաստատած պահանջ։

Այս ուղին պահպանվում է միայն պատմական հղումների աշխատանքի համար։ Այն չի պարունակում ընդունված պարզաբանում, scope-ի որոշում, ընդունման չափանիշ կամ coding authorization։ Implementation-ի համար նախկին հանդիպման պնդումները չվերականգնել։

Օգտագործել միայն manifest-ով նշանակված ընդունված պարզաբանումները և գրանցված հաստատման ապացույցը։
