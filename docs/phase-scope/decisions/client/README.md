# Client decision artifacts

Այս պանակի ֆայլերի authority-ն որոշվում է `../../../governance/DOCUMENT-MANIFEST.yaml`-ով, ոչ filename-ով։

| Prefix | Language/content role | Lifecycle | Canonical use |
|---|---|---|---|
| `21_...md` | Historical Russian detailed question set | HISTORICAL | Never implementation source |
| `21_..._HY.md` | Historical Armenian detailed question set | HISTORICAL | Never implementation source |
| `31_...md` | Historical Russian approval package | HISTORICAL | Superseded |
| `31_..._HY.md` | Historical Armenian approval package | HISTORICAL | Superseded |
| `32_..._HY.md` | Armenian consolidated draft resolution | DRAFT_CONSOLIDATION | Explanatory; not client evidence |
| `33_..._HY.md` | Armenian post-signing input request | OPERATIONAL_TEMPLATE | Does not authorize implementation |

Այս զույգերը semantic parity չեն երաշխավորում և մեկի փոփոխությունը մյուսի approval/update չի համարվում։ Scope-ի canonical source-ը verified signed TA artifact-ն է։
