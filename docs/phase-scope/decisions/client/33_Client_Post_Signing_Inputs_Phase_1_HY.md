# Փուլ I-ի մեկնարկից հետո Պատվիրատուից պահանջվող նյութերը

Հարգելի գործընկերներ,

Պայմանագրի և Փուլ I-ի տեխնիկական առաջադրանքի ստորագրումից ու մշակման աշխատանքների մեկնարկից հետո անհրաժեշտ կլինի համատեղ փակել ստորև նշված երկու աշխատանքային փաթեթները։ Դրանք լրացուցիչ գործառույթի կամ առանձին վճարման հարցեր չեն․ դրանք բժշկական համալիրի փաստացի տվյալներն ու բովանդակությունն են, որոնք անհրաժեշտ են համակարգի ճիշտ կարգավորման, սկզբնական ներբեռնման և գործարկման նախապատրաստման համար։ Մեր կողմից կտրամադրվեն լրացման հարմար ձևաչափեր, և մենք կաջակցենք նյութերի կառուցվածքավորմանը։

1. **Կազմակերպական և սկզբնական տվյալների փաթեթ։** Անհրաժեշտ կլինի տրամադրել առաջին գործարկման ստորաբաժանումների, ծառայությունների, մասնագիտությունների, հիվանդասենյակների, մահճակալների, աշխատակիցների, պաշտոնների, դերերի համապատասխանեցման, ժամանակացույցերի, ծառայությունների կատալոգի, կոդերի, գների, վճարողների, կիրառվող ICD-ի, դեղերի և լաբորատոր հետազոտությունների տեղեկատուների, չափման միավորների, հղումային միջակայքների ու կրիտիկական շեմերի պատրաստ և հաստատված տվյալները։ Մենք նախապես կտրամադրենք միասնական լրացման ձևանմուշը և տվյալների ստացումից հետո կկատարենք համաձայնեցված սկզբնական կարգավորումն ու ներբեռնումը։

2. **Փաստաթղթերի և բժշկական ձևանմուշների փաթեթ։** Անհրաժեշտ կլինի տրամադրել առաջին գործարկման համար անհրաժեշտ բժշկական և վարչական փաստաթղթերի փակ ցանկը, Ձեր մոտ առկա նմուշները, պետական կամ ներքին չափորոշիչները և բովանդակությունը հաստատող պատասխանատու մասնագետներին։ Մեր կողմից կուսումնասիրվեն տրամադրված նյութերը, կփնտրվեն հասանելի պաշտոնական կամ գործնական օրինակներ, և մենք կօգնենք ձևերի կառուցվածքավորմանն ու համակարգում տեխնիկական կարգավորմանը։ Եթե որևէ փաստաթղթի բժշկական կամ իրավական բովանդակությունը հնարավոր չլինի միանշանակ որոշել հասանելի աղբյուրներով, անհրաժեշտ մասը կտրամադրվի կամ վերջնականապես կհաստատվի Ձեր լիազորված բժշկական կամ իրավաբանական մասնագետի կողմից։

Այս երկու փաթեթների պատրաստումը կարող է սկսվել պայմանագրի ստորագրումից անմիջապես հետո և իրականացվել մշակման աշխատանքներին զուգահեռ։
