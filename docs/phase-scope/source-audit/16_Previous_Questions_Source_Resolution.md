Цель этого файла — не предлагать собственный scope, а проверить, отвечает ли сам источник на каждый ранее сформулированный вопрос.

Статусы:

- **Закрыт источником** — ответ можно зафиксировать без дополнительного решения.
- **Частично** — часть границы задана, но для договора не хватает параметров.
- **Конфликт** — разные части источника дают разные ответы.
- **Не указано** — ответа в источнике нет.

| 43 | Передаётся ли исходный код? | §10.10 прямо оставляет это отдельному договорному положению (строки 7484–7500). Данные, API и документация обязательны независимо от передачи кода. | **Не указано сознательно.** Нужное договорное решение. |
