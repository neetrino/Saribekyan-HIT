# Сводная карта функций и фаз

Статусы:

- **I** — предлагается включить в договорную Фазу I.
- **II** — предлагается исключить из Фазы I и реализовать во Фазе II.
- **III** — стратегическое развитие после стабилизации Фаз I и II.
- **Решение** — фаза зависит от ответа исполнителя или клиента.
